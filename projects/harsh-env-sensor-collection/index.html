고신뢰성 요구 환경에서의 이종 센서 데이터 수집 시스템 개발

Heterogeneous Sensor Data Collection for High-Reliability Environments

2026  |  국책 연구기관  |  Researcher

Deep Learning Sensor Fusion Data Acquisition Robustness

Overview

안개·저조도·악천후 등 열악환경에서도 강인하게 동작하는 인지 알고리즘을 연구하기 위해, 딥러닝 모델의 학습과 검증에 사용할 이종 센서 데이터를 체계적으로 수집하는 시스템을 개발했습니다.

센서 융합 기반의 열악환경 장면 이해(scene understanding)와 강인성 향상 알고리즘 연구를 데이터 측면에서 뒷받침하는 것이 핵심 목표입니다.

Key Contributions

  • 이종 센서를 통합한 열악환경 데이터 수집 시스템 설계 및 구축
  • 딥러닝 학습·검증에 적합한 데이터 획득 및 동기화 파이프라인 구현
  • 센서 융합 기반 강인성 향상 알고리즘 연구를 위한 데이터셋 확보
