저조도 파노라마 센서팩 제작

Low-Light Panorama Sensor Pack

2026  |  Aivenautics (㈜에이브노틱스)  |  Researcher

Overview

저조도 환경에서도 선명한 파노라마 영상을 얻기 위한 센서팩과 온보드 영상 처리 시스템을 개발했습니다.

다수의 스테레오 카메라를 정밀하게 캘리브레이션하여 파노라마를 생성하고, 저조도 환경에 특화된 이미지 처리 기법을 온보드에서 수행합니다.

Key Contributions

  • 스테레오 카메라 캘리브레이션 기반 파노라마 생성 파이프라인 개발
  • 저조도 환경에 특화된 이미지 처리·향상 알고리즘 구현
  • 센서팩 하드웨어 구성 및 온보드 영상 처리 시스템 통합
