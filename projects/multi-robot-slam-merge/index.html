이종 모빌리티 플랫폼 간 다중 로봇 SLAM 지도 병합 기술 개발

Multi-Robot SLAM Map Merging across Heterogeneous Platforms

2025, 국방과학연구소 (ADD), Researcher

SLAM Multi-Robot UGV UAV Map Merging FAST-LIO2

연구 개요 / Overview

고해상도/고속 처리가 가능한 주 플랫폼(UGV)과 넓은 탐색 범위를 갖는 보조 플랫폼(UAV/UGV)을 동시에 운용하여 각 플랫폼의 한계를 상호 보완하고, 개별 SLAM과 이종 플랫폼 간 데이터 융합을 통해 미지 지역의 통합 지도를 작성하는 기술을 개발하는 연구이다.

연구 역할: 다중센서 전처리 기술, 이종센서 융합 특징 추출 기술 개발

참여 연구 항목

  • Camera – LiDAR Calibration 데이터 취득 및 방법론 조사, 비교
  • LiDAR – IMU Base SLAM을 위한 Calibration 데이터 취득 및 방법론 조사, 비교
  • UGV/UAV 개별 SLAM 데이터 취득 및 SLAM 알고리즘별 Mapping 정성 성능 비교

My Role

01. Camera – LiDAR Calibration 데이터 취득 및 방법론 조사, 비교

  • 전방 카메라 Intrinsic 캘리브레이션, 2개의 360도 라이다와 전방 컬러카메라 각각 Extrinsic 캘리브레이션 진행
  • 두 개의 라이다 포인트클라우드 ICP로 라이다 간 좌표계 변환행렬 계산
  • 정량 성과 — 카메라 내부 재투영 RMSE 0.19px, 카메라–LiDAR 외부 RMSE 8mm (plane-to-point)

02. LiDAR – IMU Base SLAM을 위한 Calibration 데이터 취득 및 방법론 조사, 비교

  • IMU센서–Livox LiDAR, IMU센서–Ouster LiDAR 각각 FAST-LIO 기반 LiDAR–IMU Extrinsic 캘리브레이션 진행
  • 초기 센서팩 CAD 파라미터로 FAST-LIO 기반 라이다–IMU 캘리브레이션 알고리즘 수행
  • LIO SLAM 알고리즘은 FAST-LIO2로 맵, 라이다 오도메트리 및 맵 생성
  • 캘리브레이션된 모든 센서팩에서 실내환경 LIO 알고리즘이 동작함을 확인
  • 센서팩마다 같은 실내 환경임에도 실내 맵 생성 결과에 차이점이 보임
  • 실내환경에서 Livox 라이다는 FAST-LIO2로 맵이 잘 생성되나, 원통형 라이다인 Ouster LiDAR(128 Ch) 및 Velodyne(16 Ch)은 보다 낮은 성능으로 Drift가 있는 맵이 생성

03. 2D Occupancy Grid Map 기반 다중로봇 맵 통합 알고리즘 구현

  • 각 로봇의 Feature와 Odometry를 이용하여 2D 그리드 맵 생성
  • GPU가 없는 환경을 고려하여 ORB를 사용한 Feature 추출 및 Matching 진행
  • 로봇의 Grid 맵 이미지 간 Feature 매칭으로 각 로봇 간 초기 TF 산출
  • 산출된 초기 TF를 이용하여 두 로봇의 포인트 클라우드 ICP로 로봇 간 좌표계 TF 계산
